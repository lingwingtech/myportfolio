# Design System

## Direction
Editorial minimal / warm neutral / large typography / restrained grid.

## Core tokens
定义在 `src/styles/global.css` 的 `:root`：
- `--bg`
- `--text`
- `--muted`
- `--line`
- `--mono`

## Layout
- Desktop max width: 1440px
- Global side margin: 24px desktop, 16px mobile
- Major section spacing: 128px desktop / 88px tablet

## Typography
- Display: Inter
- Utility / metadata: DM Mono
- Editorial emphasis: Georgia italic

## UI behavior
- Fixed translucent header
- Minimal project hover feedback
- Mobile collapsible nav
- Form preserves native interaction patterns
